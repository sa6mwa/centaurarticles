# Cover fonts

These fonts are embedded by LaTeX on the cover only. The essay body retains XCharter.

- Anton Regular: https://github.com/google/fonts/blob/main/ofl/anton/Anton-Regular.ttf
- Barlow Medium: https://github.com/google/fonts/blob/main/ofl/barlow/Barlow-Medium.ttf

Downloaded from the Google Fonts repository on 5 November 2026. Both are supplied
under the SIL Open Font License 1.1; the corresponding license files are included.
The slanted title uses a typesetting transformation of Anton, not a modified font file.
